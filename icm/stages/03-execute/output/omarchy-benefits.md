# Omarchy OS — Benefits

## What it is
Arch Linux + Hyprland tiling window manager, pre-configured by DHH (David Heinemeier Hansson).

## Key benefits
1. **Zero config** — tiling WM, themes, keybinds, and tools work out of the box
2. **Arch base** — rolling release, AUR access, always latest packages
3. **Hyprland** — modern Wayland compositor, smooth animations, low resource use
4. **Sensible defaults** — dev tools, fonts, terminal, and CLI utilities pre-installed
5. **Fast workflow** — keyboard-driven, no mouse needed for window management
6. **Minimal bloat** — only what you need, nothing you don't

## Trade-offs
- Arch = manual maintenance, occasional breakage
- Hyprland = Wayland-only, some apps need workarounds
- Not beginner-friendly if you've never used Linux

## Verdict
Best for: developers who want a beautiful, fast, keyboard-driven Linux desktop without spending days configuring it.
