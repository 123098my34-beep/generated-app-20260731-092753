# Omarchy OS — Free AI Agent?

## Short answer
No built-in AI agent. Omarchy is a desktop environment (Arch + Hyprland), not an AI platform.

## What it has
- Pre-configured dev tools, terminal, CLI utilities
- No native AI assistant or agent framework

## What you can add
- **Ollama** — run local LLMs (free, open-source)
- **Open WebUI** — chat interface for local models
- **Aider** — AI pair programming in terminal
- **Continue** — VS Code AI assistant extension

## Verdict
Omarchy doesn't ship with a free AI agent, but its Arch base makes it easy to install one.
